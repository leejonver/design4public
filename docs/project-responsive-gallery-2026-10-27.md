# 프로젝트 상세 반응형 사진 검증 (2026-10-27)

## 벤치마크

- [Vitra Unix Chair](https://www.vitra.com/en-un/product/details/unix-chair-four-star): 대표 이미지 원본 1440×576, 렌더링 645×258로 동일 비율. 본문 홍보 이미지의 cover 방식은 상세 사진 전체 노출 목적과 달라 채택하지 않음.
- [ArchDaily Redmond Library](https://www.archdaily.com/1039822/redmond-library-miller-hull-partnership): 대표 사진 원본 750×411 → 640×351, 다음 사진 750×521 → 640×445. 두 사진 모두 computed object-fit: contain. 이미지별 원본 비율을 유지하는 사례.
- Norm Architects도 조사했으나 상세 페이지가 응답하지 않아 레이아웃 판단 근거에서 제외.

## 적용

기존 520px 고정 높이와 1760px 컨테이너에서는 큰 화면의 사진/텍스트 폭이 약 856/774px였다. 프로젝트 상세 컨테이너만 최대 2240px로 확장하고, 높이를 컨테이너 내부 폭의 45%와 화면 높이의 80% 중 작은 값으로 정했다(440~960px 제한). 사진 전환 중 높이는 일정하다.

사진 폭은 원본 비율 × 높이를 기준으로 하되 기본 최소 60%, 텍스트 최소 320px를 보장한다. 861px 근처에서는 텍스트 최소 너비를 우선하므로 사진 비중이 60%보다 조금 작을 수 있지만 텍스트보다 넓다. 세로/매우 넓은 사진은 contain 여백을 허용해 전체를 보인다. 860px 이하에서는 사진 위/텍스트 아래 배치와 원본 비율 높이를 유지한다.

## ego lite 실측

TOSS 사옥 첫 사진, CSS viewport / DPR 1, 데스크톱 에뮬레이션. 실제 모니터 배율에 따라 CSS viewport는 물리 해상도와 다를 수 있다. 스크롤바 포함 여부로 약 1~8px 차이가 날 수 있다.
