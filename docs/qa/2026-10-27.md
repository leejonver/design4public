# Admin and public-site QA — 2026-10-27

## Reproduced issues and changes

- At 390px, the expanded 280px admin sidebar squeezed the project heading into
  a vertical column. Small screens now default to the collapsed sidebar; opening
  it overlays the page instead of reducing content width. Desktop preference is
  preserved. The collapsed sidebar header now fits its 72px width.
- The admin search field shrank to roughly icon width next to filters on mobile.
  It now occupies its own full-width row below 640px.
- Admin used an external Pretendard CSS import despite already shipping the font.
  It now serves the existing local variable font with `font-display: swap`.
- E2E previously reused port 3000 and the development DB, which can contain a
  production copy. Tests now use a dedicated Supabase project (55321/55322), app
  server (3100), build directory, mailbox, and actual fixture image objects.
  Remote/default development DB URLs are rejected before provisioning users.
- Cold development compilation caused repeated setup/navigation timeouts. E2E
  now builds and runs the production server, covering production cache behavior
  without weakening feature-test assertions.

## Cleanup
